# One-Line Roast: The Gadget You Use Every Day

Entry for the make.fun bounty
[u-daring-gecko-25-one-line-roast-the-gadget-you-use-3d6aa610](https://make.fun/bounty/u-daring-gecko-25-one-line-roast-the-gadget-you-use-3d6aa610).

A program (`main.py`, Python 3.13, stdlib-only) that writes one original
roast line to `/output/entry.txt`.

## The text

> My Kindle holds two thousand books and still shows me the same three I bought in 2019, like a library that only stocks my regrets.

130 characters (1–200 gate), UTF-8, one line, deterministic.

## Run

```sh
python3 main.py   # writes /output/entry.txt, exit 0
```
